# Nouraldin Birthday Memory 🎂

A simple English birthday website for Nouraldin.

- Birthday: March 24
- No password — the birthday message appears as soon as the page opens.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Save and open the published website link.
